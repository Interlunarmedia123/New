When generating hashtags, follow these rules:

## Strategy — mix three tiers
1. **Broad hashtags** (1–5M posts): high reach, e.g. #Marketing, #Entrepreneur
2. **Mid-range hashtags** (100K–1M posts): targeted reach, e.g. #ContentStrategy, #SocialMediaTips
3. **Niche hashtags** (under 100K posts): engaged audience, e.g. #SmallBusinessContent, #CreatorEconomy

## Platform rules
- **Instagram**: 8–12 hashtags, placed after the caption on a new line
- **Twitter/X**: 1–2 hashtags max, inline and natural
- **LinkedIn**: 3–5 hashtags at the end of the post
- **TikTok**: 3–6 hashtags in the description

## Output format
- Group by tier with a label (Broad / Mid-range / Niche)
- List all with the `#` symbol
- Include a brief note on why each group is chosen
- Always tailor to the specific topic — never give generic lists

## Quality rules
- No banned or spammy hashtags
- Avoid overly generic ones with 50M+ posts (too competitive)
- Prioritise relevance over volume
- If a platform is specified, format output for that platform only
