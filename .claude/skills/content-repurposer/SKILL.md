When repurposing content for social media:

## Step 1 — Analyse the source content
- Identify the 3–5 key insights or takeaways
- Find the most quotable or shareable lines
- Note any statistics, stories, or examples that stand alone well

## Step 2 — Create platform-specific versions

### Twitter/X thread (if content is rich enough)
- Tweet 1: Hook — the most compelling insight as a bold statement
- Tweets 2–6: One key point per tweet, each self-contained
- Final tweet: Summary + link back to original content

### LinkedIn post
- Lead with the single most valuable insight
- Expand with 2–3 supporting points from the content
- End with a question related to the topic
- 150–250 words, short paragraphs

### Instagram caption
- Pick the most relatable or inspiring moment from the content
- Write a personal, story-driven caption around it
- Add a CTA (save this, share with someone who needs it)
- 8–12 hashtags at the end

## Rules
- Do not just summarise — extract and punch up the best bits
- Each platform version should feel native to that platform
- Preserve the original author's voice and intent
- If only one platform is requested, only produce that one
- Ask which platform(s) to target if not specified
